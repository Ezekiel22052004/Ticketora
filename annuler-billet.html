Demander l’annulation d’un billet

Scannez le QR code de votre billet avec votre téléphone, puis saisissez le code du billet ci-dessous. Vous devez aussi renseigner l’e-mail et le numéro de téléphone utilisés lors du paiement.

Pour une annulation volontaire d’un billet, le remboursement prévu est de 90 % du prix du billet; les 10 % restants couvrent les frais de retrait dans la limite du coût réel, puis le solde revient à l’administrateur. Si l’organisateur annule l’événement, le prix du billet est remboursé à 100 %; les frais de service de 5 % ne sont pas remboursés au client. Le transfert doit être confirmé par le prestataire.
